    CSS SELECTORS:

         Definition:
                A CSS selector is used to select HTML elements that you want to style.


                Syntax: example
                     
                     h1--- HTML element
                     { -- flower brackets  
                          
                           color: blue;   --- property : value;            
                        
                         } 
         
         +-------------------+--------+------------------+-----------------------------+
         | Selector          | Symbol | Example          | Selects                     |
         +-------------------+--------+------------------+-----------------------------+
         | Element Selector  | None   | p                | All <p> elements            |
         | Class Selector    | .      | .high            | Elements with class "high"  |
         | ID Selector       | #      | #title           | Element with ID "title"     |
         | Universal Selector| *      | *                | All HTML elements           |
         | Group Selector    | ,      | h1, p            | Multiple HTML elements      |
         +-------------------+--------+------------------+-----------------------------+
         
         Examples:
         
         1. Element Selector

            p {
                color: red;
            }
         
         2. Class Selector

            .high {
                color: red;
            }
         
         3. ID Selector

            #title {
                color: blue;
            }
         
         4. Universal Selector

            * {
                margin: 0;
            }
         
         5. Group Selector
         
            h1, h2, p {
                font-family: Arial;
            }
