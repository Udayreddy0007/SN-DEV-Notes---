what is HTML:HTML is a markup language  --- 

it defines the structure of a webpage / used to display content over the web page


What is the structure of HTML:

in HTML Everything is  consider as tags  <(open tag / open angular bracket)   />(close tag/ closed angular bracket)

Structure of html

<!DOCTYPE html> -- Tells the browser the document type is html

<html> -- root element of the html
 
   <head> -- where we can store information about our webpage
     <title>
              we write the name of the browser tab
     </title>
     metadata-information
     CSS references
     JS references      

   </head>

         <body> - Store the data which is displayed over the browser where a end can see
          <h1></h1>
          <p></P>
          <img>
          <a>    

         </body>

</html>
